代码提交：`4e96f53` 实现 worker；`31a70b9` 修复 quoted/structured credential 脱敏及 BrokenPipe 收尾；`8ebc0cb` 修复大写环境变量带引号、空格、转义引号时的脱敏遗漏。上述中间失败均已补回归并关闭，没有未解决的审查阻断项。

- `processes.py` 持久化 request、PID/PGID 和事件日志；独立进程组与启动 barrier，确保 running record fsync 后才放行。spawn/cancel 串行，启动各阶段取消都不会提前运行 SDK。
- HTTP execute 流式返回 NDJSON；消费方断连不取消 worker，父进程继续 drain。terminal 在协议 EOF/退出状态校验后才发布，错误路径合成唯一失败终态。
- Cancel/restart 对整个进程组先 TERM、超时 KILL，确认无活动进程后转 awaiting_finalize；startup recovery 完成后才 ready。awaiting/terminal 的重复取消不再触碰历史 PGID。
- 限制 stderr 与协议行大小，日志/公开 event 字符串递归脱敏；删除 execution 先清理所属辅助文件、最后删除 tombstone，失败可重试。不增加依赖，不改变 Go SandboxProvider 扩展点。
